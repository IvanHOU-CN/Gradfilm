Card links

One link per card. Write them now, match names later. Until a card has a name, it shows the general "Happy graduation!" version.

  1. Check the site address below. It fills in by itself.
  2. For each card: tap Copy, then in NFC Tools go to Write, Add a record, URL/URI, paste and write the tag. Pencil the card number on the card and tick Written.
  3. Later, type each friend's first name next to their card number, then copy the names.js text at the bottom into GitHub.
